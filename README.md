# 🎓 UCSD Fall 2026 Class Schedule & Campus Map Studio

An interactive, responsive schedule planner and campus navigation studio designed for **UC San Diego (Fall 2026 Registration)**.

---

## 🌟 Live Demo & Mobile Web App
- 📱 **Live Netlify Web App**: [https://dynamic-pothos-6e5b61.netlify.app](https://dynamic-pothos-6e5b61.netlify.app)
- 📅 **Direct Calendar Sync**: Download `UCSD_Fall_2026_Schedule.ics` and tap to import all classes into Apple Calendar & Google Calendar.

---

## ✨ Features
1. **Interactive Timetable Grid**:
   - Visual 5-day matrix (Mon–Fri, 9:00 AM – 8:00 PM).
   - Real-time collision detection (0 conflicts confirmed).
   - Color-coded badges for Lectures, Discussions, and Labs.

2. **Campus Location & Google Maps Integration**:
   - Tap any class block on the calendar to view:
     - Exact Building Name, Building Number, and Room Number (e.g. *Warren Lecture Hall #625, Room 2005*).
     - College Neighborhood (e.g. *Earl Warren College*, *John Muir College*, *Sixth College / Central Hub*).
     - 1-Tap direct **Google Maps walking directions** to that building on campus!
     - 1-Click copy for Section Booking IDs.

3. **Pre-Configured Conflict-Free Plans**:
   - **★ Plan A (16.0 Units)**: Baseline conflict-free schedule.
   - **Plan B (Backup 1)**: Alternate sections.
   - **Plan C (Fast WL)**: Minimal waitlist queue.
   - **★ Plan D (+ MATH 183)**: Full 16-unit baseline with statistical methods for 12.0 unit financial aid qualification.
   - **⭐ My Plan 1**: Custom user-saved schedule stored in browser `localStorage`.

4. **1-Click Export & Booking**:
   - **Export .ICS Calendar**: Instant import to smartphone calendar apps with 10-minute notifications and room details.
   - **Copy All Booking IDs**: Formats all TSS Section IDs for quick paste during Second Pass registration.
